# Minecraft Building Academy

Curso interativo de construção para Minecraft Bedrock, pensado para ensinar arquitetura e composição enquanto o jogador evolui de uma casa inicial até uma vila completa e um Nether Hub.

## Direção inicial

- Minecraft Bedrock
- Survival-first
- Progressão sequencial de aprendizado
- Primeiro vertical slice: Starter House
- Evolução planejada: casa inicial → base → vila → Nether Hub

> Status: protótipo inicial em desenvolvimento.
