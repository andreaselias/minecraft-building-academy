# Produto

## Objetivo

Ensinar construção no Minecraft Bedrock por meio de uma sequência de projetos conectados, em vez de oferecer apenas uma biblioteca de builds para copiar.

O jogador deve terminar o curso sabendo reconhecer e aplicar princípios de composição, proporção, profundidade, ritmo, paleta, telhados, paisagismo e planejamento urbano.

## Princípios

1. **Survival-first** — cada projeto respeita a progressão natural de materiais.
2. **Aprender enquanto constrói** — cada etapa explica pelo menos um princípio visual.
3. **Um único mundo que evolui** — construções anteriores permanecem relevantes.
4. **Blueprints reproduzíveis** — toda construção é descrita bloco a bloco.
5. **Bedrock como referência principal** — estados e nomes de blocos são validados para Bedrock.
6. **Compatibilidade de paleta** — oferecer substituições coerentes quando possível.
7. **Progressive disclosure** — o modo Learn não entrega a solução antes da tentativa.
8. **Etapas menores que camadas** — uma mesma camada pode ter mais de uma intenção construtiva.

## Modos

### Learn

O jogador recebe um objetivo, uma pergunta ou um pequeno desafio antes de ver a solução quando isso ajuda a desenvolver uma técnica reutilizável.

A solução pode ser revelada depois da tentativa. O sistema então explica o raciocínio visual por trás daquela escolha.

### Build

Mostra imediatamente o blueprint da etapa atual. É o modo para quem quer executar a construção sem a camada didática adicional.

Os dois modos usam a mesma sequência de etapas e o mesmo blueprint.

## Vertical slice

A Casa Inicial deve ser totalmente reproduzível usando apenas a aplicação.

Recursos presentes no vertical slice:

- blueprint bloco a bloco;
- sequência guiada de etapas;
- mais de uma etapa dentro da mesma camada;
- visualização 3D;
- etapas anteriores em ghost;
- vistas superior, frontal e lateral;
- seleção de bloco com coordenadas e estados;
- lista de materiais total e por etapa;
- modo Learn com desafios e revelação;
- modo Build direto;
- progresso salvo localmente;
- trilha do curso;
- CI de build.

## Critério de qualidade

O vertical slice está pronto para validação quando um jogador consegue:

1. iniciar a Casa Inicial sem outra referência;
2. entender quais blocos pertencem à etapa atual;
3. voltar para etapas já concluídas;
4. identificar orientação de stairs e outros blocos direcionais;
5. perceber ao menos um princípio arquitetônico reutilizável em cada grupo importante de etapas.
